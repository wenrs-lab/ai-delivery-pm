## 一、十项巡检维度

| # | 维度 | 检查问题 | 判定 | 证据/偏差 |
|---|------|----------|------|-----------|
| 1 | 进度 | 关键路径任务是否按基线完成？偏差天数？ | | |
| 2 | 里程碑 | 下一个里程碑的准入条件是否齐备？ | | |
| 3 | 外部依赖 | 客户数据/环境/审批/第三方是否按最晚到位日推进？ | | |
| 4 | 范围 | 是否有未走变更单的新增需求或口头承诺？ | | |
| 5 | 问题 | 上期问题是否按期关闭？有无逾期未动？ | | |
| 6 | 资源 | 关键角色是否到位、是否被抽调、多项目是否抢人？ | | |
| 7 | 质量 | 缺陷趋势、测试用例通过率、返工量是否异常？ | | |
| 8 | AI 效果 | 指标是否可达基线？调优轮次是否够？预期是否失控？ | | |
| 9 | 沟通 | 客户/销售/管理层最近一次同步是否有未决事项？ | | |
| 10 | 验收 | 验收材料、签字链路、合规留痕是否按倒排推进？ | | |

## 二、红黄绿判定口径

| 颜色 | 判定条件 | 动作 |
|------|----------|------|
| 🟢 | 全部维度无偏差，或偏差在缓冲内 | 正常推进，周报记录 |
| 🟡 | 出现偏差但本周可纠偏，依赖未到位但有替代方案 | 指定责任人 + 纠偏期限，下次巡检复查 |
| 🔴 | 影响里程碑/验收、逾期问题未动、承诺超产能、客户预期失守 | **当日登记 P0/P1 并升级**，同步交付负责人 |

## 四、升级触发条件（命中即升级，不押后）

- 关键路径偏差 > 缓冲天数
- P0/P1 问题超过 24h 无责任人或无方案
- 销售已对客户承诺未经评审的范围/时间
- 客户数据/环境最晚到位日即将击穿
- 验收指标出现不可达迹象
- 连续两次巡检同一问题仍为 🟡/🔴
