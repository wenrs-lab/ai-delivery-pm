## 三、闭环六步

```
登记 → 分级定性 → 指定唯一责任人 + 期限 → 跟踪进展 → 验证关闭 → 归档复盘
```

- **唯一责任人**：一个条目只写一个名字，协同方另列，杜绝「大家一起负责」
- **定性归属**：先判是流程问题还是能力问题，避免把所有锅归给「沟通不畅」
- **关闭验证**：由提出方或项目经理确认，不能由责任人自证关闭
- **重开规则**：同一问题二次出现 → 升级一级并做根因分析

## 四、逾期与升级

| 情形 | 动作 |
|------|------|
| 到期前 1 天无进展 | 提醒责任人并抄送其上级 |
| 逾期 1 天 | 升级一级，24h 内出补救方案 |
| 逾期 3 天或跨部门推不动 | 提交交付负责人决策，附可选方案与影响 |
| 需客户配合才能解 | 当天转成客户侧正式沟通事项，写入周报 |
